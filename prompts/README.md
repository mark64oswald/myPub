# myPub Super Prompts

This directory contains comprehensive prompts (super prompts) for various knowledge base tasks.

## Available Prompts

| Prompt File | Purpose |
|-------------|---------|
| `index-book.md` | Index a new ePub into the catalog |
| `extract-concepts.md` | Extract concepts from chapters |
| `generate-skill.md` | Generate a domain skill file |
| `create-pattern.md` | Create a new pattern from sources |
| `research-topic.md` | Deep research on a topic |
| `compare-perspectives.md` | Compare author perspectives |
| `learning-path.md` | Generate a learning path |
| `build-system.md` | Build a system using patterns |

## Usage

These prompts are designed to be used with Claude. Copy the prompt content, customize the variables (marked with `{{variable}}`), and paste into your Claude conversation.

Alternatively, reference them as custom commands in Claude Desktop.

## Structure

Each super prompt includes:

- **Goal**: What the prompt accomplishes
- **Prerequisites**: What needs to be in place
- **Variables**: Parameters to customize
- **Steps**: The workflow Claude will follow
- **Expected Output**: What you'll get back
