# Custom Commands

This directory contains custom command definitions for use with Claude.

## Available Commands

| Command | Description |
|---------|-------------|
| `/kb-search` | Search the knowledge base for content |
| `/kb-compare` | Compare author perspectives |
| `/kb-prereqs` | Show learning prerequisites |
| `/kb-pattern` | Get a pattern with variations |
| `/kb-generate-skill` | Generate a skill file from chapters |
| `/kb-learning-path` | Generate recommended reading order |
| `/kb-index` | Index new books into the catalog |
| `/kb-status` | Show knowledge base statistics |

## Usage

Commands can be invoked in Claude conversations:

```text
/kb-search dimensional modeling
/kb-compare Kimball vs Inmon
/kb-prereqs HCC Risk Adjustment
/kb-pattern healthcare.dimensional.fct_claim_line
```
